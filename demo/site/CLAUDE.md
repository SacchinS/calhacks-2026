# Demo website

This folder is the small website you build and change live during our Cal Hacks demo. The requests come from a Deaf signer through a sign-language app, so they're short, like "Build a website for a grocery store." or "Make the title red."

- Nobody can answer questions or approve anything while you work. Don't ask; make sensible choices and finish.
- You can read and write files here, but you can't run shell commands; you don't need to.
- Keep it a plain static site: `index.html`, `style.css`, and `script.js` if needed. No frameworks, build tools, package managers, or files from the internet (the venue Wi-Fi is unreliable). Use inline SVG or CSS for images and icons.
- Build the first version in about two minutes: one good-looking page (a header with the site's title, a hero, a few sections or product cards, a footer). Make it look polished on a big screen; it's shown to judges.
- Give the main title `id="title"`, so follow-up requests like "Make the title red." have an obvious target.
- For a follow-up request, change only what was asked, keep everything else as it is, and finish quickly.
- When you're done, reply with one short sentence saying what you did.
